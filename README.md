# 🥗 Smart Diet Planner

A modern and responsive Personal Diet Planning web application built using HTML, CSS, and JavaScript.

This project helps users calculate:

- 🔥 BMR (Basal Metabolic Rate)
- ⚡ TDEE (Total Daily Energy Expenditure)
- 🥗 Personalized Diet Suggestions

---

# 🚀 Features

- Responsive Modern UI
- Glassmorphism Design
- Interactive Animations
- BMR Calculator
- TDEE Calculator
- Dynamic Diet Recommendations
- Mobile Friendly
- Easy to Use Interface

---

# 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
